## 3. Source packages

Import rules are in section 9. Signatures below are an **implementation choice**; they exist so agents write to one interface. Change one only through a task in `TRACKER.md`.

### 3.1 `config.py`

Constants only, no logic, no imports from the project. See `BACKEND_SCHEMA.md` §5 for the list. Paths (`ROOT`, `RAW_CSV`, `CLEAN_CSV`, `ARTIFACTS_DIR`, `REPORTS_DIR`) are built here with `pathlib`.

### 3.2 `data/`

| File | Public interface | Milestone |
|---|---|---|
| `load.py` | `load_raw(path=RAW_CSV) -> pd.DataFrame`; `file_sha256(path) -> str` | M0-05, M1-01 |
| `schema.py` | `RAW_COLUMNS: list[str]`; `validate_raw(df) -> None` (raises on a missing column) | M1-01 |
| `clean.py` | `clean(raw: pd.DataFrame) -> pd.DataFrame`; `write_clean(df, path=CLEAN_CSV) -> None` | M1-02 |
| `groups.py` | `base_model(s) -> str`; `spec_fingerprint(df) -> pd.Series`; `dup_groups(df) -> list[int]`; `group_audit(df) -> dict` | M1-03 |
| `split.py` | `outer_split(df) -> tuple[np.ndarray, np.ndarray]` (train and test `row_id`s); `build_cv_splits(train_df) -> list[tuple[np.ndarray, np.ndarray]]`; `brand_holdout_splits(train_df)`; `positions_for(frame, row_ids) -> np.ndarray` | M1-04, M1-05 |

### 3.3 `features/`

| File | Public interface | Milestone |
|---|---|---|
| `spec.py` | `FEATURES`, `CATEGORICAL`, `BINARY`, `NUMERIC`, `FEATURE_GROUPS`, `FORBIDDEN_FEATURES`; `to_model_frame(df) -> pd.DataFrame` (selects `FEATURES`, casts booleans to int) | M2-01 |
| `build.py` | `build_preprocessor(kind: Literal["tree", "linear"]) -> ColumnTransformer` | M2-02 |

### 3.4 `models/`

| File | Public interface | Milestone |
|---|---|---|
| `evaluate.py` | `mdape(z_hat, price)`, `r2_log(z_hat, price)`, `mae(z_hat, price)`, `per_segment_errors(...)`, `paired_wins(a, b)`, `classification_report_dict(...)`, `brand_holdout(...)`, `bootstrap_cis(...)` (optional) | M3-01, M3-03, M3-05, M4-04 |
| `regression.py` | `regression_candidates() -> dict`; `tune_and_select(X, y, cv_splits) -> SelectionResult`; `fit_final(...)` | M3-02, M3-04 |
| `classification.py` | `classification_candidates() -> dict`; `select(...)`; `compare_calibration(...)`; `fit_final(...)` | M4-01 to M4-03 |
| `uncertainty.py` | `band(price)`; `q_level(res, level=0.8)`; `fit_q_bands(price, z_oof) -> dict`; `interval(z, q_band) -> tuple` | M5-01 |
| `explain.py` | `permutation_importance_by_group(...)`; `sensitivity(...)`; `sensitivity_text(...)` | M5-02 |
| `comparables.py` | `build_index(df) -> dict`; `top5(index, query) -> list[int]` | M5-03 |

`evaluate.py` exports no function that computes MdAPE on log residuals.

### 3.5 `analytics/`

| File | Public interface | Milestone |
|---|---|---|
| `aggregates.py` | `normalise_filters(params) -> tuple`; `build_view(view_id, filters, frame) -> dict` (the envelope in `BACKEND_SCHEMA.md` §8.2) | M6-01, M6-02, M6-04 |
| `value_finder.py` | `score_rows(frame, oof, q_band) -> pd.DataFrame`; `rank(rows, include_outliers) -> pd.DataFrame` | M6-03 |

### 3.6 `service/`

| File | Public interface | Milestone |
|---|---|---|
| `artifacts.py` | `save_bundle`, `load_bundle`, `write_manifest`, `check_versions(manifest) -> GuardResult` | M5-06 |
| `predictor.py` | `Predictor.from_artifacts()`; `predict`, `classify`, `options`, `analytics_view`, `metrics`, `health` | M5-07, M7-03 |

`service/` never imports Flask. `webapp/` imports only `phonelens.service.predictor`.

## 4. Scripts

Thin wrappers. Each has a `main()` and a `if __name__ == "__main__"` guard, and holds no logic.

| Script | Make target | Reads | Writes |
|---|---|---|---|
| `clean_data.py` | `make data` | raw CSV | cleaned CSV, `reports/group_audit.json` |
| `train.py` | `make train` | cleaned CSV | `regressor`, `classifier`, `comparables`, `splits.json`, `manifest.json` |
| `evaluate.py` | `make evaluate` | artifacts, **test rows (the only reader)** | `metrics.json`, `model_card.md`, figures |
| `build_analytics.py` | `make analytics` | artifacts, cleaned CSV | `analytics.json` |

`scripts/__init__.py` must exist so `python -m scripts.train` works from the repository root.

| Path | Role |
|---|---|
| `css/tokens.css` | The only place raw colours, radii, spacing and fonts are defined |
| `css/base.css`, `layout.css`, `components.css`, `pages.css` | Reset and typography; grid and sections; component classes; page-specific rules. All reference tokens. |

No file under `static/` loads anything from the network.

## 8. Naming conventions

| Item | Convention |
|---|---|
| Python | `snake_case` modules, functions and variables; `PascalCase` classes; `UPPER_CASE` constants; type hints on every public function |
| Columns and JSON keys | `snake_case`, identical across CSV, Python, JSON and query strings |
| Tests | `test_<area>.py`; function names say the behaviour: `test_unseen_brand_returns_200_with_warning` |
| CSS | Component classes `.c-button`, `.c-card`; state classes `is-active`, `is-error`; tokens as `--color-*`, `--space-*`, `--radius-*` |
| JS | ES modules, named exports, `camelCase`; one file, one role |
| Task and requirement IDs | `M3-04`, `FR-P2`, `QG-05`, `R-08` as in `TRACKER.md` |
| Commits | `M3-04: fit and save the regressor` (task ID first) |

## 9. Import and dependency rules

```
webapp  ->  service.predictor  ->  models, analytics, service.artifacts
models  ->  features  ->  data  ->  config
analytics -> data
scripts ->  models, analytics, data, service.artifacts
```

`test_import_graph.py` fails when `webapp` imports anything but `phonelens.service.predictor`, when anything under `src/` imports `scripts` or `webapp`, when `service/` imports Flask, or when a module other than `config.py` hard-codes a constant that `config.py` defines.

## 10. Configuration files

### 10.1 `pyproject.toml` (tested)

```toml
[build-system]
requires = ["setuptools>=68"]
build-backend = "setuptools.build_meta"

[project]
name = "phonelens"
version = "0.1.0"
requires-python = ">=3.12"
dynamic = ["dependencies"]

[tool.setuptools.dynamic]
dependencies = { file = ["requirements.txt"] }

[tool.setuptools.packages.find]
where = ["src"]

[tool.pytest.ini_options]
testpaths = ["tests"]
pythonpath = ["src", "."]
addopts = "-ra --strict-markers"
markers = ["smoke: browser smoke tests, run with make smoke"]

[tool.coverage.run]
source = ["src/phonelens"]

[tool.ruff]
line-length = 100
target-version = "py312"

[tool.ruff.lint]
select = ["E", "F", "I", "B", "UP", "N", "SIM"]
```

`requires-python = ">=3.12"` matches the verified environment. Relax it only after G0-02 shows a lower version works. Dependencies are read from `requirements.txt` so there is one list. `pythonpath = ["src", "."]` lets tests import both `phonelens` and `webapp`.

### 10.2 `Makefile` (dry-run tested; recipes use a tab character)

```make
PY ?= python
VENV ?= .venv

.PHONY: setup data train evaluate analytics run smoke test lint ci all

setup:
	$(PY) -m venv $(VENV)
	$(VENV)/bin/python -m pip install -r requirements.txt -r requirements-dev.txt
	$(VENV)/bin/python -m pip install -e .

data:
	$(PY) -m scripts.clean_data

train:
	$(PY) -m scripts.train

evaluate:
	$(PY) -m scripts.evaluate

analytics:
	$(PY) -m scripts.build_analytics

run:
	flask --app webapp run

smoke:
	$(PY) -m pytest tests/smoke -m smoke

test:
	$(PY) -m pytest --cov --cov-report=term-missing --cov-fail-under=80

lint:
	ruff check .
	ruff format --check .

ci: lint test

all: data train evaluate analytics ci
```

On Windows without `make`, run the recipe lines directly; the README lists each. `make all` runs data, train, evaluate, analytics and ci in order.

## 12. Optional Antigravity layout

`AGENTS.md` at the repository root is enough: Antigravity reads it as a rule. Per the sources checked while writing this (a third-party guide and Google's own custom-agents page, neither read from the installed IDE), the IDE reads `AGENTS.md` from version 1.20.5, a single rules file is capped at 12,000 characters, and workspace rule folders are `.agents/rules/` with `.agent/rules/` kept for older projects. Verify in the installed version (task M0-01).

If a second layer is useful later:

```
.agents/
├── rules/       # standing context, one topic per file, each under 12,000 characters
├── workflows/   # repeatable procedures triggered with /, for example start-task, finish-task
└── skills/      # on-demand capabilities with a SKILL.md each
```

Keep `AGENTS.md` as the single source of project rules. Rule files should point to it, not repeat it.

## 13. What this document adds to the spec

The spec's tree in §4 does not list these. They are **implementation choices**:

| Addition | Why |
|---|---|
| `scripts/clean_data.py` and `scripts/__init__.py` | `make data` needs an entry point; `python -m scripts.<name>` needs a package |
| `artifacts/splits.json` | Splits must be reproducible and auditable as `row_id` lists |
| `reports/group_audit.json` | The spec requires it in §3.1 but does not place it in the tree |
| `tests/conftest.py`, `tests/fixtures/`, `tests/smoke/` | Test support and the optional browser tests |
| `webapp/templates/partials/*`, `static/js/nav.js`, CSS split | Concrete file layout for the UI |
| `docs/` and `docs/design/` | Home for the derived documents and the token source |
| `pyproject.toml` and `pip install -e .` in `make setup` | `src/` layout needs the package importable; tested in a toy project |
| `requirements.lock` committed | Exact versions for the committed artifacts |
